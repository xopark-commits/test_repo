# 점심 메뉴 투표 텔레그램 봇 만들기

## 바이브 코딩 워크숍 (4시간)

> Google Drive 스프레드시트를 읽어서 텔레그램으로 점심 메뉴 알림을 보내는 봇을 만듭니다.
> **코드는 직접 작성하지 않습니다. AI에게 프롬프트로 요청해서 만듭니다!**

---

## 전체 흐름

```
Google Sheets (점심 메뉴 데이터)
        ↓ Python이 읽어옴
   텔레그램 봇이 알림 전송
        ↑ 슬래쉬 커맨드로 조회/투표
```

---

## 준비물

- Python 3.10 이상 설치
- 본인이 사용하는 AI 도구 (ChatGPT, Claude, Cursor, Copilot 등 아무거나)
- Google 계정
- 텔레그램 앱 (휴대폰에 설치)

---

# STEP 0. 프로젝트 폴더 만들기 (5분)

원하는 위치에 폴더를 만들고, 터미널(명령 프롬프트)을 엽니다.

```bash
mkdir lunch-bot
cd lunch-bot
```

---

# STEP 1. 텔레그램 봇 만들기 (15분)

텔레그램에서 나만의 봇을 만들어 봅니다. 코딩이 아니라 **채팅**으로 만듭니다!

## 1-1. BotFather에게 봇 생성 요청

1. 텔레그램 앱을 열고 검색창에 **@BotFather** 를 검색합니다
2. BotFather와 대화를 시작합니다
3. 아래 순서대로 메시지를 보냅니다:

```
/newbot
```

4. BotFather가 봇 이름을 물어봅니다 → 아무 이름이나 입력 (예: `우리팀 점심봇`)
5. 봇 username을 물어봅니다 → **반드시 `bot`으로 끝나야 합니다** (예: `ourteam_lunch_bot`)
6. 성공하면 **토큰**을 줍니다 → 이것을 반드시 메모합니다!

```
예시: 7123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

> ⚠️ 이 토큰은 비밀번호와 같습니다. 다른 사람에게 공유하지 마세요!

## 1-2. 내 Chat ID 확인하기

1. 텔레그램에서 방금 만든 봇을 검색해서 대화를 시작합니다
2. 봇에게 아무 메시지나 보냅니다 (예: `/start` 또는 `안녕`)
3. 웹 브라우저에서 아래 주소를 엽니다 (YOUR_BOT_TOKEN을 본인 토큰으로 교체):

```
https://api.telegram.org/botYOUR_BOT_TOKEN/getUpdates
```

4. 결과에서 `"chat":{"id":숫자}` 부분의 **숫자**가 내 Chat ID입니다
5. 이것도 메모합니다!

```
예시: 1234567890
```

> 💡 결과가 비어있다면? 봇에게 메시지를 보낸 후 다시 새로고침하세요.

# STEP 2. Google Cloud 설정 (30분)

Python에서 Google Sheets를 읽으려면 **서비스 계정**이 필요합니다.
처음이라 복잡해 보이지만, 한 단계씩 따라하면 됩니다!

## 2-1. Google Cloud 프로젝트 만들기

1. https://console.cloud.google.com 에 접속합니다 (Google 로그인)
2. 상단의 프로젝트 선택 버튼 클릭 → **새 프로젝트** 클릭
3. 프로젝트 이름: `lunch-bot` (아무거나 OK) → **만들기** 클릭
4. 프로젝트가 생성되면 해당 프로젝트가 선택되어 있는지 확인

## 2-2. Google Sheets API 활성화

1. 좌측 메뉴 → **API 및 서비스** → **라이브러리**
2. 검색창에 `Google Sheets API` 검색
3. **Google Sheets API** 클릭 → **사용** 버튼 클릭
4. 다시 라이브러리로 돌아가서 `Google Drive API` 검색
5. **Google Drive API** 클릭 → **사용** 버튼 클릭

## 2-3. 서비스 계정 만들기

1. 좌측 메뉴 → **API 및 서비스** → **사용자 인증 정보**
2. 상단 **+ 사용자 인증 정보 만들기** → **서비스 계정** 클릭
3. 서비스 계정 이름: `lunch-bot` → **만들기 및 계속** 클릭
4. 역할 선택: **편집자** (Editor) → **계속** 클릭
5. **완료** 클릭

## 2-4. JSON 키 파일 다운로드

1. 방금 만든 서비스 계정을 클릭합니다
2. **키** 탭 클릭
3. **키 추가** → **새 키 만들기** → **JSON** 선택 → **만들기**
4. JSON 파일이 자동 다운로드됩니다
5. 이 파일을 `lunch-bot` 폴더에 넣고, 이름을 `credentials.json`으로 변경합니다

> ⚠️ 이 파일도 비밀번호와 같습니다! GitHub 등에 절대 올리지 마세요.

## 2-5. 서비스 계정 이메일 확인

다운로드한 `credentials.json` 파일을 메모장으로 열면, `client_email` 항목이 있습니다.

```
예시: lunch-bot@lunch-bot-12345.iam.gserviceaccount.com
```

이 이메일 주소를 메모합니다. (다음 단계에서 사용)

# STEP 3. Google Sheets에 데이터 올리기 (10분)

## 3-1. 엑셀 파일 업로드

1. https://drive.google.com 에 접속합니다
2. 제공된 `점심메뉴_투표.xlsx` 파일을 드래그하여 업로드합니다
3. 업로드된 파일을 더블클릭하면 Google Sheets로 열립니다
4. (자동으로 변환되지 않으면) 상단 메뉴 → **파일** → **Google 스프레드시트로 저장**

## 3-2. 서비스 계정에 공유하기

이 단계가 핵심입니다! Python이 시트를 읽으려면 권한이 필요합니다.

1. Google Sheets 우측 상단 **공유** 버튼 클릭
2. STEP 2-5에서 메모한 **서비스 계정 이메일**을 입력
3. 권한: **편집자** 선택
4. **보내기** 클릭

## 3-3. 스프레드시트 ID 확인

Google Sheets URL에서 ID를 복사합니다:

```
https://docs.google.com/spreadsheets/d/여기가_스프레드시트_ID/edit
```

슬래시(`/d/`)와 다음 슬래시(`/edit`) 사이의 긴 문자열이 ID입니다.

```
예시: 1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms
```

## 미션 1: 환경 설정 파일 만들기

### AI에게 줄 프롬프트:

```
파이썬 프로젝트를 하나 만들려고 해.

아래 정보를 .env 파일에 저장하는 구조를 만들어줘:
- TELEGRAM_BOT_TOKEN: 텔레그램 봇 토큰
- TELEGRAM_CHAT_ID: 텔레그램 채팅 ID
- GOOGLE_SHEETS_ID: 구글 스프레드시트 ID  
- GOOGLE_CREDENTIALS_FILE: credentials.json

.env.example 파일도 만들어서 실제 값 대신 설명을 넣어줘.

그리고 필요한 패키지 목록을 requirements.txt로 만들어줘:
- gspread (Google Sheets 연동)
- oauth2client (Google 인증)
- python-telegram-bot (텔레그램 봇)
- python-dotenv (.env 파일 로딩)
- APScheduler (스케줄러)
```

### 해야 할 일:

1. AI가 만들어준 `.env.example`을 복사해서 `.env` 파일을 만듭니다
2. `.env` 파일에 본인의 실제 토큰, Chat ID, 스프레드시트 ID를 입력합니다
3. 패키지를 설치합니다:

```bash
pip install -r requirements.txt
```

### AI에게 줄 프롬프트:

```
Python으로 Google Sheets에서 데이터를 읽어오는 코드를 만들어줘.

조건:

```


## 미션 5: 텔레그램 슬래쉬 커맨드 만들기

### AI에게 줄 프롬프트:

```
텔레그램 봇에 슬래쉬 커맨드를 추가하고 싶어.
기존 telegram_bot.py를 확장하거나 새 파일(bot_commands.py)을 만들어줘.

추가할 커맨드:
1. /today - 오늘의 점심 메뉴 현황을 보여줌
   - sheets_manager.py에서 오늘 메뉴를 읽어와서 이쁘게 표시
   
2. /vote 메뉴이름 - 특정 메뉴에 투표
   - 예: /vote 김치찌개
   - sheets_manager.py의 투표수 올리기 함수 호출
   - 성공하면 "김치찌개에 투표했습니다! (현재 6표)" 응답
   - 해당 메뉴가 없으면 "오늘 메뉴에 '김치찌개'가 없습니다" 응답

3. /help - 사용 가능한 명령어 안내

조건:
- python-telegram-bot 라이브러리의 Application 사용
- 봇이 계속 실행되면서 명령어를 기다림 (polling 방식)
- .env에서 설정값 로딩
```

### 테스트:

```bash
python bot_commands.py
```

텔레그램에서 봇에게 아래 명령어를 보내봅니다:
- `/help` → 명령어 안내가 오면 성공
- `/today` → 오늘 메뉴가 오면 성공
- `/vote 김치찌개` → 투표 완료 메시지가 오면 성공

### 프롬프트 예시:

```
이 에러가 발생했어. 원인과 해결 방법을 알려줘:

(여기에 에러 메시지 전체를 붙여넣기)

내 환경:
- Windows / Mac
- Python 3.x
- 사용 중인 라이브러리: gspread, python-telegram-bot, APScheduler
```

### 흔한 에러들:

| 증상 | 원인 | 해결 |
|------|------|------|
| `ModuleNotFoundError` | 패키지 미설치 | `pip install 패키지명` |
| `FileNotFoundError: credentials.json` | 경로 문제 | credentials.json이 같은 폴더에 있는지 확인 |
| Google Sheets 접근 에러 | 공유 안 됨 | STEP 3-2 다시 확인 (서비스 계정에 공유했는지) |
| `Forbidden: bot was blocked` | 봇 대화 미시작 | 텔레그램에서 봇에게 `/start` 보내기 |
| `Chat not found` | Chat ID 오류 | STEP 1-2 다시 진행 |
| `Unauthorized` | 토큰 오류 | `.env`의 봇 토큰이 정확한지 확인 |

최종 폴더는 이런 구조가 됩니다:

```
lunch-bot/
├── .env                  ← 내 설정값 (비공개)
├── .env.example          ← 설정값 예시
├── credentials.json      ← Google 인증 키 (비공개)
├── requirements.txt      ← 필요한 패키지 목록
├── sheets_manager.py     ← Google Sheets 읽기/쓰기
├── telegram_bot.py       ← 텔레그램 메시지 전송
```
